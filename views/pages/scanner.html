Escáner de Alimentos

Aquí integraremos OpenAI para reconocer comidas y ayudarte a tomar decisiones de control.

Estado actual

Sube una foto o escribe una breve descripción y pulsa "Analizar". Si proporcionas solo la descripción, la consulta se enviará a OpenAI.





Notas

  • 1. Necesitas una API key de OpenAI configurada en el servidor como la variable de entorno OPENAI_API_KEY.
  • 2. Si subes imagen, por ahora se guarda en /uploads/. Para reconocimiento automático se requiere un modelo con visión y ajustar el backend para enviar la imagen al modelo vision-capable.
  • 3. Nunca pegues tu API key directamente en el frontend. Revoca claves expuestas y usa variables de entorno.
